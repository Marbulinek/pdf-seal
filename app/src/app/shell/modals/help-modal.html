Certificates

The Certificates section reports on any signatures found in the document: integrity, the certificate chain behind each one, and whether required fields are still waiting to be signed. Optional tools (enabled in Settings) add a standalone certificate scratchpad, a trust simulation against a root CA bundle you supply, and certificate modification for building test documents.

Download the demo root CA to try trust simulation against the sample document.

# PDF Seal Portal

Send a PDF from the page you're on straight to PDF Seal.

## How it works

The extension works only on sites listed in **Settings → Allowed domains**. On any other site, the send button is disabled and the popup tells you which pattern to add. Nothing is read from a page unless its URL matches one of those patterns.

Click **Send via PDF Seal Portal** to scan the tab. If it finds exactly one PDF, that PDF is sent right away. If it finds several, the popup lists them and you click the one to send.

Broken links and files that aren't PDFs are left out. A few kinds can't be verified in advance; they're listed with a "Couldn't be checked in advance" note and are never sent automatically.

## What it can send

- PDF viewers embedded in the page (including form values and annotations made in the viewer)
- A tab that is itself a PDF (values typed into Chrome's built-in viewer are not included)
- Embedded PDFs and links to PDFs
- PDFs generated by the page
- Forms that produce a PDF (works same-origin or with CORS)

A PDF from another origin is fetched by the extension itself. The first time, Chrome asks for permission for that origin.

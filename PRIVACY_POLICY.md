# PDF Seal Portal - Privacy Policy

PDF Seal Portal respects user privacy and handles document data with strict boundaries.

## Data Processing & Privacy

The extension inspects web page elements (e.g., embedded PDF viewers, document links, blobs, or captured PDF streams) solely to extract PDF documents upon explicit user action or on configured origins. All processing happens locally on your device.

## No Remote Analytics or Tracking

We do not collect, store, track, or sell any personal data, usage metrics, or browsing history.

## Data Storage

The extension uses `chrome.storage.local` exclusively to retain local user configurations, whitelist settings, and session states locally on your machine.

## Host Permissions & Content Scripts

Network requests and page injections are strictly gated by domain whitelists and explicit user-initiated actions. PDF data is transferred only directly to the target PDF Seal environment.
